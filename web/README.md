# 🧭 강원대학교 실시간 공고 큐레이션 웹사이트: 프로그램 · 대회 · 장학금

> **국립강원대학교 공식 포털 5개 링크 실시간 연동**  
> 교내외 프로그램, 대회/공모전, 장학금 공고를 실시간으로 크롤링하여 **제목, 신청일시, 행사 날짜, 링크**를 최근 순으로 제공하고, 각 섹션별 검색창을 통해 현재 신청 가능한 최신 공고를 즉시 찾아주는 웹 애플리케이션입니다.

## ✨ 2. 핵심 기능

1. **독립된 3개 섹션별 실시간 검색창**
   - **프로그램 검색창**: 워크숍, 특강, 도서관, 전시, 어학 등 3개 출처 통합 검색
   - **대회 검색창**: 해커톤, 경진대회, 엠블럼, 아이디어 공모전 등 검색
   - **장학금 검색창**: 근로장학, 창업장학, 생활비, 국가장학, 사정관 등 검색
2. **필수 4대 정보 카드 & 테이블 제공**
   - 📌 **제목**: 공고 원문 제목 (강조 표시)
   - 🗓️ **신청일시**: 접수 기간 및 신청 마감일
   - ⏰ **행사 날짜**: 행사 진행 일시 및 마감 일정
   - 🔗 **링크**: 클릭 시 해당 공식 공고 페이지로 바로 이동
3. **스마트 필터링 및 최근 순 정렬**
   - **최근 등록순**: 최신 공고부터 역순 정렬
   - **가능한 것만 보기**: 현재 신청/참여 가능한 공고 기본 필터링 (사이드바에서 전체 보기 토글 가능)
   - **카드 뷰 & 테이블 뷰**: 사용자 선호에 따른 뷰 모드 전환 지원
   - **10분 캐싱 & 원클릭 새로고침**: 빠른 응답속도와 최신 데이터 동기화 제공
